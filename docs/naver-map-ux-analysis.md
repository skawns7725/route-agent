# 네이버지도 길찾기 동작 분석

## 관찰 범위

2026년 11월 18일에 공개 PC 웹과 모바일 웹을 브라우저에서 확인했다. 모바일 관찰 범위는 길찾기 진입과 출발지 검색 화면까지다.

| 항목 | 관찰 |
|---|---|
| PC 장소 선택 | 출발지와 도착지는 검색 후 후보의 장소명과 주소를 보고 확정한다. 충남대학교 정문은 대덕캠퍼스, 보운캠퍼스, 병원 정문 후보가 표시됐다. |
| PC 자동차 경로 | 출발지와 도착지 확정 후 경로 목록에서 소요 시간, 거리, 통행료, 주요 구간의 소통 상태를 비교할 수 있었다. |
| PC 경유지 | 자동차 길찾기 입력 영역에서 경유지를 지정할 수 있었다. |
| 모바일 웹 | 지도 메뉴의 길찾기는 네이버 검색의 빠른길찾기로 이어졌다. 출발지 버튼은 별도 장소 검색 화면을 열었다. |

조회 예시인 용운동행정복지센터에서 충남대학교 대덕캠퍼스 정문까지 실시간 추천은 22분, 14km, 통행료 800원이었다. 무료 우선은 24분, 13km, 통행료 0원이었다. 수치는 관찰 시점의 표시값이다.

## 가는 길에 적용 설계

1. 출발지, 목적지, 경유지, 경로 후보와 선택 경로를 여정 상태로 관리한다. 입력 문자열은 장소를 선택하기 전까지 검색어로 유지한다.
2. 모바일은 지도와 접을 수 있는 하단 패널을 함께 사용한다. 패널에서 후보를 선택하면 지도 표시와 대화 문맥을 함께 갱신한다.
3. 자동차 경로 후보는 시간 차이와 통행료부터 비교한다. 정체 정보가 제공되면 구간과 기준 시점을 표시한다.
4. “가는 길에 맥날”은 현재 여정의 경유 후보를 비교한다. 제공되는 추가 시간, 거리, 주차 정보로 비교하고, “거기 리뷰는?”은 마지막으로 제시한 매장에 연결한다.
5. 사용자가 경유 후보를 선택하면 경로를 재계산한다. 실패하면 이전 경로를 유지하고 새 경유지를 적용 대기 상태로 표시한다.

## 첫 구현의 확인 기준

- 동명 장소 후보의 주소를 보고 출발지와 목적지를 올바르게 확정할 수 있다.
- 같은 여정의 경로 후보에서 시간과 통행료 차이를 읽을 수 있다.
- 경유지 한 곳을 선택한 뒤 경로와 추가 시간이 함께 갱신된다.
- 재계산 실패 시 이전 경로가 화면에 남고 다시 시도할 수 있다.
- 공개 카카오 지도 SDK는 지도 표시를 담당한다. 경로, 교통, 리뷰는 실제 연결된 출처와 확인 수준을 표시한다.

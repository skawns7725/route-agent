# 가는 길에 Android

Android Studio에서 이 디렉터리를 열거나 JDK 17, Gradle 8.9 및 Android SDK 35 환경에서 `gradle :app:assembleDebug`를 실행합니다.

앱의 패키지명은 `kr.gigonggyo.routeagent`입니다. 첫 화면에 표시되는 설치본의 키 해시를 카카오 개발자 콘솔 Android 플랫폼에 패키지명과 함께 등록한 뒤, 기존 앱의 네이티브 앱 키를 입력합니다. 서명 인증서가 바뀌면 새 키 해시를 등록합니다.

카카오맵 SDK가 앱 내부에 대전 지도를 표시합니다. 경로 대화 탭은 기존 웹 데모의 모의 시나리오를 사용합니다.
